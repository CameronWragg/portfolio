# Portfolio

Cameron Wragg's personal site, written mainly for hiring managers in data engineering. Its secondary readers are makers and hobbyists.

## Language

**Repo**:
A public repository on Cameron's GitHub account. It is the raw source a Project is built from.
_Avoid_: Project (when you mean the GitHub-side thing)

**Project**:
A Repo as it is presented on the site. Every eligible Repo becomes a Project automatically.
_Avoid_: Card, entry, item

**Experience**:
A role in Cameron's working history, shown on the Experience page.
_Avoid_: Job, position, CV entry

**Profile Widget**:
A summary in the site footer of Cameron's presence on an external platform (GitHub, LinkedIn).
_Avoid_: Badge, social link

**Override**:
Hand-written adjustments to how one specific Project is presented, such as a better name, description or tags, or hiding it.
_Avoid_: Customisation, config entry

**Featured Project**:
A Project Cameron has marked to be shown first and highlighted.
_Avoid_: Pinned, starred

**Banner**:
The ASCII-art rendering of a Project's name that stands in for an image.
_Avoid_: ASCII art, logo, cover image

**Education**:
A university qualification Cameron holds or is studying for. It is kept separate from Experience.
_Avoid_: Degree, school, Experience (for study)

**Tag**:
A label on a Project that readers can filter by. Tags come from the Repo's languages, its GitHub topics and any Override tags.
_Avoid_: Topic (GitHub's term), label, category
